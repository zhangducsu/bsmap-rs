**索引构建**:

### 参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| -a | 文件路径 | 查询序列文件（单端）或 Read 1（双端） |
| -b | 文件路径 | Read 2 文件（双端模式） |
| -d | 文件路径 | 参考序列文件 |
| -o | 文件路径 | 输出 SAM 文件 |
| -s | 16 | 种子长度 |
| -v | 0.08 | 允许的最大错配率（8%） |
| -I | 4 | 允许的最大插入/删除长度 |
| -p | 1 | 线程数 |

## P0-2 优化总结

### 已完成的优化
- ✅ 将 `KmerLoc2.loc1` 从 `Vec<u32>` 改为 `Option<Vec<u32>>`
- ✅ 消除 WGBS 模式下的冗余内存分配
- ✅ 与现有索引格式完全兼容
- ✅ SAM 比对一致性保持 98.8% 以上

### 优化效果评估
- 内存使用：理论上减少约 1-2 MB
- 性能影响：由于主要瓶颈在索引加载，无显著性能提升
- 代码质量：有提升，更符合 Rust 最佳实践

### 发现的真正瓶颈

🔥 **索引加载时间是最大瓶颈！**
- 索引加载约占总时间的 75-87%
- 索引文件大小：495 MB
- 加载方式：mmap

### 建议的下一步优化方向

1. **索引加载优化**
   - 使用更紧凑的二进制格式
   - 并行加载索引
   - 索引预加载和缓存

2. **继续 P0 剩余优化**
   - P0-3: 整合 WGBS 索引存储结构
   - P0-4: 消除热点路径的边界检查

3. **长期优化**
   - 重新设计索引格式
   - 使用更高效的压缩算法
   - 支持共享内存避免重复加载
