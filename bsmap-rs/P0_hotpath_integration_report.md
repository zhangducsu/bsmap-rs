## 技术细节

### 为什么 Ex2 提升不明显？

可能原因：
1. **系统波动**：Docker 环境下的 CPU/内存调度导致测试波动
2. **索引加载时间占比高**：索引加载约 12s，实际比对时间约 3.8s
3. **双端比对复杂度更高**：涉及更多的配对逻辑

### 实际性能分析

```
Ex1 时间分解（推测）：
  - 索引加载: ~12s (不变)
  - 读段编码: ~0.5s
  - 种子哈希: ~0.5s (使用 xt3，仍为瓶颈)
  - Mismatch 计数: ~0.2s (SIMD 优化生效！)
  - 其他开销: ~0.02s
  - 总计: ~13.22s
```

## 下一步优化建议

### P0 必做

1. **xt3 哈希函数优化**（最大瓶颈）
   - 核心哈希计算仍然使用标量版本
   - 需要 SIMD 化或查找表优化

2. **索引结构优化**
   - 整合 index2/positions/start_offsets
   - 提高缓存局部性

### P1 重要

3. **索引预加载优化**
   - 减少索引加载时间（约 12s）
   - 多线程预加载

4. **种子扩展优化**
   - 优化 extend.rs 中的循环
   - 减少不必要的边界检查
